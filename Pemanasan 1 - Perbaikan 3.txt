    Terdapat juga satu wadah tambahan bernama wadah B yang isinya kosong. Tersedia juga buku dan pulpen.
    -   Deklarasi
    a, b, c adalah variabel tunggal bertipe integer
    jumlah_pengambilan adalah variabel tunggal bertipe integer
    a <- 0
    b <- 0
    c <- 0
    jumlah_pengambilan <- 0

    1.  Pada baris pertama di halaman pertama pada buku, tulis "Warna Merah: "
    2.  Pada baris kedua di halaman pertama pada buku, tulis "Warna Kuning: "
    3.  Pada baris ketiga di halaman pertama pada buku, tulis "Warna Biru: "
    4.  Jika variabel jumlah_pengambilan di bawah 100,
        4a. Maka    4a1.    Ambil satu kelereng dari wadah A
                    4a2.    Periksa warna pada kelereng tersebut
                    4a3.    Jika kelereng berwarna merah
                            4a3a.   Maka,       4a3a1.  a <- a + 1
                            4a3b.   Selain itu, 4a3b1.  Jika kelereng berwarna kuning
                                                        4a3b1a. Maka,       4a3b1a1.    b <- b + 1
                                                        4a3b1b. Selain itu, 4a3b1b1.    c <- c + 1
                    4a4.    Pindahkan kelereng ke wadah B
                    4a5.    jumlah_pengambilan <- jumlah_pengambilan + 1
                    4a6.    Kembali ke Aksi 4.
    5.  Pada baris pertama di halaman pertama pada buku, tulis nilai dari a di kanan "Warna Merah: "
    6.  Pada baris kedua di halaman pertama pada buku, tulis nilai dari b di kanan "Warna Kuning: "
    7.  Pada baris ketiga di halaman pertama pada buku, tulis nilai dari c di kanan "Warna Biru: "
